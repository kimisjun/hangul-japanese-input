# 「ハングル発音 → 日本語入力ツール」ユーザーマニュアル

**Hancom Hangul（HWP）専用／日本語版取扱説明書**
対象プログラム：`HangulJapaneseInput.App.exe`

---

## 1. 本ツールについて

本ツールは、**Hancom Hangul（HWP）上で、日本語の発音をハングルで入力し、ショートカットキーでひらがな・カタカナ・漢字に変換するWindows用補助ツール**です。

例：

- `와타시`（watashi）→ `わたし`
- `테레비`（terebi）→ `テレビ`
- `니혼`（nihon）→ `日本`／`二本`

> **重要**：本ツールはMicrosoft Word、メモ帳、Webブラウザー用ではありません。変換機能は、入力先としてHancom Hangul（HWP）がアクティブになっているときだけ動作します。

## 2. 動作に必要なもの

- Windowsパソコン
- Hancom Hangul（HWP）がインストールされていること
- 韓国語キーボード（Microsoft IME）でハングルを入力できること
- 本ツールの配布フォルダー一式

本ツールは64ビットWindows向けに作成されています。配布時は、実行ファイルだけを別の場所へ移動せず、配布フォルダー内のファイルを同じ場所に保つことを推奨します。

## 3. 起動方法

1. 配布されたZIPファイルを任意のフォルダーに展開します。
2. `HangulJapaneseInput.App.exe`をダブルクリックします。
3. メイン画面が表示され、**「HWP 자동 변환 사용」**にチェックが入っていることを確認します。
4. Hancom Hangul（HWP）を起動し、文書内をクリックして入力できる状態にします。

Windowsの警告画面が表示された場合は、配布元が信頼できることを確認してから操作してください。

## 4. 日本語Windowsで韓国語入力を追加する方法

本ツールでは日本語の読みを**ハングル文字で入力**するため、Windowsに韓国語キーボードを追加します。

### Windows 11

1. **設定** → **時刻と言語** → **言語と地域**を開きます。
2. **言語の追加**を選択します。
3. 「韓国語」を検索して追加します。
4. 入力時に `Windowsキー + Space` を押し、韓国語入力へ切り替えます。
5. キーボード設定は一般的な**2ボル式（두벌식）**を使用します。

変換後、日本語または元の入力言語へ戻す場合も `Windowsキー + Space` を使用できます。

## 5. 基本操作

1. 本ツールを起動します。
2. Hancom Hangul（HWP）を前面に表示します。
3. 韓国語入力へ切り替えます。
4. 変換したい日本語の発音を、**スペースを入れず1語としてハングルで入力**します。
5. 目的に合わせてショートカットキーを押します。

| 目的 | 入力例 | キー | 結果例 |
|---|---|---|---|
| ひらがな | `와타시` | `Space` | `わたし` |
| カタカナ | `테레비` | `F7` | `テレビ` |
| 漢字候補 | `니혼` | `Ctrl + Space` | `日本`／`二本` |

### ひらがな変換

`와타시`と入力した直後に`Space`を押すと、直前の語が`わたし`に置き換わります。変換後には通常の語間スペースも入力されます。

### カタカナ変換

`테레비`と入力した直後に`F7`を押すと、`テレビ`に置き換わります。

ノートパソコンによっては、`F7`を使うために`Fn + F7`を押す必要があります。

### 漢字変換

`니혼`と入力した直後に`Ctrl + Space`を押すと、登録されている漢字候補が表示されます。

- `↑`／`↓`：候補を移動
- `Enter`：選択した候補を確定
- `Esc`：変換を取り消す
- 候補をダブルクリック：その候補を確定

## 6. 変換プレビューの使い方

メイン画面下部の**「변환 미리보기」**欄では、ハングルを入力して変換結果を事前に確認できます。

たとえば`와타시와`を入力すると、次のように表示されます。

- ひらがな：`わたしは`
- カタカナ：`ワタシハ`
- 漢字候補：該当候補がある場合のみ表示

プレビュー欄は確認用です。HWP文書を変換するには、HWP本文に語を入力してショートカットキーを押してください。

## 8. 常駐動作と終了方法

メイン画面右上の`×`を押しても、プログラムは終了せず、Windowsの通知領域に常駐します。

通知領域のアイコンを右クリックすると、次の項目が表示されます。

| 画面の韓国語 | 日本語での意味 |
|---|---|
| `설정 창 열기` | 設定画面を開く |
| `자동 변환 사용` | 自動変換を使用する／一時停止する |
| `끝내기` | プログラムを終了する |

完全に終了するには、通知領域のアイコンを右クリックして**「끝내기」**を選択します。

## 10. トラブルシューティング

### ショートカットを押しても変換されない

- 本ツールが起動しているか確認します。
- **「HWP 자동 변환 사용」**にチェックが入っているか確認します。
- Hancom Hangul（HWP）が前面のアクティブなアプリになっているか確認します。
- 読みをハングルで入力した直後にショートカットを押します。
- 入力した語が未登録、または対応していない表記である可能性があります。

### Spaceを押すと通常の空白になる

変換できる語として認識されなかった場合、通常のSpaceキーとして処理されます。プレビュー欄で対応状況を確認してください。

### F7で音量や画面機能が動く

ノートパソコンの機能キー設定が優先されています。`Fn + F7`を試すか、パソコン側のファンクションキー設定を確認してください。

### Ctrl + Spaceで漢字候補が出ない

その読みに対応する漢字が辞書に登録されていない可能性があります。漢字変換は、登録済みの語だけで利用できます。

### 画面を閉じたのに動作が続く

正常な動作です。`×`はウィンドウを隠すだけで、プログラムは通知領域で動き続けます。完全に終了する場合は通知領域から**「끝내기」**を選びます。

## 11. 使用上の注意と現在の制限

- 本ツールは、日本語IMEのように文全体の文法や文脈を解析するものではありません。
- 基本的に、直前に入力した1語を変換します。
- ひらがな・カタカナは対応する発音表記から変換されますが、すべての外来語、促音、長音、特殊表記を完全に処理できるわけではありません。
- 漢字候補は内蔵辞書に登録された語に限られます。
- 日本語として自然な漢字・助詞・送り仮名になっているか、確定後に必ず確認してください。
- 変換処理では直前の語を一時的にクリップボードへコピーし、処理後に元のクリップボード内容を戻します。環境によっては、他のクリップボード管理ソフトの履歴に残る場合があります。
- HWP以外のアプリが前面にあるとき、本ツールは変換を行いません。

## 12. すぐに試せる練習

1. 本ツールとHancom Hangul（HWP）を起動します。
2. HWP本文で韓国語入力に切り替えます。
3. `와타시`と入力して`Space`を押します。→ `わたし`
4. `테레비`と入力して`F7`を押します。→ `テレビ`
5. `니혼`と入力して`Ctrl + Space`を押します。
6. `↑`／`↓`で`日本`を選び、`Enter`で確定します。

以上で基本操作は完了です。
